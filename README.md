# RAID Ultimate Assistant

Türkçe Android yardımcı uygulaması — RAID: Shadow Legends için kadro, ekipman ve takım planlama aracı.

## Bu sürüm
Bu paket başlangıç Android Studio projesidir. Şu anda Türkçe ana ekran ve özellik menüsü bulunur. Şampiyon/eşya veritabanı, OCR, Hydra öneri motoru ve farm hesaplayıcıları sonraki geliştirme adımlarıdır.

## Gereksinimler
- Android Studio (Hedgehog veya daha yeni)
- Android SDK 35
- JDK 17

## Açma
1. ZIP dosyasını çıkarın.
2. Android Studio > Open ile `RAID_Ultimate_Assistant` klasörünü seçin.
3. Gradle senkronizasyonunun tamamlanmasını bekleyin.
4. Bir Android cihaz veya emülatör seçip Run'a basın.

Uygulama yalnızca yardımcı analiz/planlama içindir; RAID oyun dosyalarını, sunucularını veya hesap verilerini değiştirmez.
